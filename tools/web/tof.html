Configuration

Common

Every register on the configuration page (0x22–0xdf)

Pick the zone layout with Preset: it sets the focal-plane mode and its timing together, then reloads this page. Changes are highlighted until applied. Applying writes the whole page; the sensor keeps what it accepts and the page shows what it read back. Field names follow ams's register map; see the TMF8829 datasheet for their full meaning.
